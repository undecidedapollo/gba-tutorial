# gba-tutorial

A Rust, Game Boy Advance repository with lessons on how to build Game Boy Advance ROMs using the Rust Programming Language.

The tutorial is broken into lessons, with each lesson being its own branch. `main` reflects the latest lesson.

The tutorial can be found at [jonahnestrick.com](https://jonahnestrick.com/blog/rust-gba-tutorial-1/) - https://jonahnestrick.com/blog/rust-gba-tutorial-1/

### Lessons:

[Lesson 01 - Draw pixels on the screen](https://github.com/undecidedapollo/gba-tutorial/tree/lesson-01) - https://github.com/undecidedapollo/gba-tutorial/tree/lesson-01
